Manual Send Message

To send this message manually, using a terminal emulator to talk to a TNC:

  1. Ensure your radio is on the correct frequency for {{BBS}}. See the SCCo ARES/RACES Packet BBSes page for the proper frequencies.
  2. Ensure your TNC has the county standard settings. See the Standard TNC Settings page for details.
  3. Ensure your TNC is identifying as {{IDENT}}. On most TNCs, this is a MY {{IDENT}} command.
  4. Tell your TNC to connect to {{BBS}}. On most TNCs, this is a C {{BBS}}-1 command.
  5. Once connected, copy the message below (using the "Copy" button) and paste it into your terminal emulator.

Note: if your TNC is a Kantronics KPC-3 Plus or compatible, this software can handle the TNC for you. Go to the Incident Configuration page, set the Connection Type to "Serial+TNC", supply the necessary details, and then use the "Connect" button on the Incident page to send and receive messages.
